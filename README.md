# Toko Bunga Cendana

A responsive e-commerce web application for a flower shop, created for a college project.

## Features
- **Frontend**: Built with modern HTML, CSS, Bootstrap 4, and Swiper. Completely responsive layout.
- **Backend**: PHP-based shopping cart and checkout mock system.
- **WhatsApp Integration**: The checkout system automatically calculates total orders and generates a pre-filled WhatsApp link to easily contact the seller and complete the purchase.

## Pages Include
- Home (`index.html`)
- Shop (`shop.html`)
- Product Details (`product-details.html`)
- About Us (`about-us.html`)
- Contact Us (`contact-us.html`)
- Shopping Cart (`cart.php`)
- Checkout (`checkout.php`)

## How to Run Locally
1. Ensure you have a PHP server installed (like XAMPP, Laragon, or MAMP).
2. Place this project inside the `htdocs` or `www` directory.
3. Open `http://localhost/toko_bunga` (or your chosen directory name) in the browser.
